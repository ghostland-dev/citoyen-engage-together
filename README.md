# Citoyen Engage

Civic engagement platform connecting volunteers with solidarity actions.

## Features

- Solidarity action listings and details
- Volunteer page and profile
- Dashboard

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/citoyen-engage-together.git
cd citoyen-engage-together
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
